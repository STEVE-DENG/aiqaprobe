PureEval

AI Judge Agent

Agent 的进步，让评测来说话。

本地优先的 Agent 与 Skill 评测工作台。管理评测集、批量执行任务，用规则与模型共同评分，把每次改动放回同一套标准中比较。

评分有依据
规则校验、自定义评分标准、多 Judge 汇总与人工复核。
失败可追溯
保留步骤轨迹、模型调用与执行产物，查看评分理由和失败分组。
迭代可比较
对比基线与候选版本的质量、Token、成本和耗时，结合留出集与晋级门禁评估改动。
