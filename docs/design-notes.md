# AIQA Probe 视觉与内容方向

- 任务：让访客立即了解两个真实开源项目，并按主题进入可持续积累的研究笔记。
- 色彩：雾白 `#f5f8f7`、纸白 `#ffffff`、深青 `#163d42`、松绿 `#146d60`、薄荷 `#dceee7`、沙金 `#b58a43`。
- 字体：Avenir Next 负责英文项目名称，PingFang SC / Microsoft YaHei 负责中文阅读；等宽字体只用于请求与代码。
- 布局：首页以左侧大标题、右侧研究文件夹索引开场；项目用两张带功能示意的宽卡并排；笔记有独立索引和独立文章页。
- 识别：节点连接成 Q，尾部是验证勾。首页文件夹表达工具与笔记的积累，不展示虚构性能或实时状态。
- 克制：不用雷达、全屏网格、主题切换或无关演示。保留清楚的导航、阅读留白、可操作的反馈入口。
- 阅读：按用户反馈加大正文、导航、笔记与辅助信息字号，加深文字颜色；手机导航分两行，避免字号缩小。
- 复核：通用营销模板无法解释本站的项目与资料关系，因此主视觉采用可点击的研究文件夹，所有数字来自实际内容。
